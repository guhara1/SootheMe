# 히어로 / OG 이미지

이 폴더의 **`hero.jpg`** 파일이 다음에 한 번에 사용됩니다.

- 모든 지역 페이지 상단 히어로 배경
- 메인 페이지 히어로 배경
- 소셜 공유 썸네일(og:image) · 스키마 대표 이미지

## 업로드 방법
이 폴더에 **`hero.jpg`** 라는 이름으로 이미지를 올리면 끝입니다.
(코드가 `/assets/img/hero.jpg` 를 참조하므로 파일명을 정확히 맞춰 주세요.)

- 권장 크기: 가로 1600px 이상, 가로형(예: 1600×900 또는 1200×630)
- 형식이 PNG/WEBP 라면 파일명을 `hero.jpg` 대신 그대로 두고
  `src/config.mjs` 의 `HERO_IMAGE` 와 `assets/css/main.css` 의 `--hero-img` 경로만
  같은 확장자로 바꾸면 됩니다.

이미지가 아직 없으면 히어로는 어두운 배경색으로 정상 표시됩니다(깨지지 않음).
